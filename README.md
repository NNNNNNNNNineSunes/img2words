# 屏幕框选 OCR V3.1

一个 Windows 桌面小工具：按住 **Ctrl + 鼠标左键拖动**框选屏幕上的中英文文字，松开后识别并复制到剪贴板，随后在任意应用中按 **Ctrl+V** 粘贴。

- 本地 OCR，不需要 Tesseract 或云端识别服务。
- 支持系统托盘后台运行。
- 保留最近 100 条文字历史，可定位高亮、删除、复制单条/全部/选中文字。
- 窗口可调整大小，历史左右栏可拖动调整比例。

## 快速启动

1. 安装 **Windows 11 + 64 位 Python 3.11**。推荐使用 [python.org 安装程序](https://www.python.org/downloads/windows/)，保留 pip、Tcl/Tk 和 Python Launcher 组件。
2. 下载仓库 ZIP 并解压，或使用 Git 克隆到可写的文件夹。
3. **从 Windows 资源管理器双击 [start.cmd](<start.cmd>)。** 首次启动会自动创建虚拟环境、安装依赖并检查随依赖提供的 OCR 模型，需要联网；安装完成后识别可离线进行。

无需管理员权限。请使用启动脚本，不要直接启动虚拟环境中的 Python。

## 使用

1. 等待程序就绪，然后按住 Ctrl、左键拖动框选文字；松开后等待识别完成。
2. 在目标应用中按 Ctrl+V。框选时可按 Esc 取消；取消或没有识别到文字不会覆盖剪贴板。
3. 就绪后程序会自动隐藏到通知区域，也可手动最小化。双击托盘图标或右键“显示主窗口”恢复窗口。
4. 在“历史记录”中点击左侧条目，右侧对应内容立即高亮；可拖动中间分隔栏、跨条选择文字并复制。
5. **窗口 X 默认隐藏到托盘，不是退出。** 请用窗口或托盘菜单中的“退出”结束程序。托盘不可用时保留任务栏入口，X 则退出。

请勿同时启动多个实例。

## V3.1：公式 OCR（实验版）

- **默认关闭，每次启动均需重新勾选**“启用公式 OCR（实验版）”；不改变 Ctrl 文字识别流程。
- 勾选后，**左 Alt + 左键拖动**输出行内 LaTeX（`$…$`）；**左 Alt+Shift + 左键拖动**输出独立公式（`$$…$$`）。右 Alt 不启用公式模式；Ctrl 优先走文字模式。
- 采用 RapidLaTeXOCR **0.0.9 / CPU**，在独立子进程中识别。截图到识别共用 30 秒截止时间，失败、超时或取消后可继续使用文字模式；清理失败时本次运行会停用公式功能。
- Esc 可取消。剪贴板提交前会再次检查取消状态；**已经提交的复制无法撤回**。公式识别可能产生错误或缺失，请对照原图检查，不能把 LaTeX 可渲染当作数学正确。
- 公式依赖使用独立环境，不替换文字 OCR 的依赖。可选离线安装入口为 [setup-formula.ps1](<setup-formula.ps1>)，同目录需保留 [formula_setup.py](<formula_setup.py>) 和 [requirements-formula-lock.txt](<requirements-formula-lock.txt>)；脚本默认以自身目录为项目根目录，支持 `-ProjectRoot` 和 `-LocalModelsPath` 的本地绝对路径参数。
- 当前开发机已完成真实 CPU 推理、模型校验和原生退出测试；**全新机器的安装脚本端到端流程、物理快捷键/混合 DPI/UIPI、复杂公式准确率仍需人工验收**。不更改 PowerShell 执行策略或申请管理员权限来绕过失败。

## 本地数据与隐私

- 截图仅用于本机识别，不持久化截图，也不向云端发送 OCR 内容。
- 成功识别并复制的文字会以明文保存在本机历史中，最多 100 条；不需要时可在历史窗口清空。剪贴板内容会保留到被替换。
- 日志包含状态、错误、字符数及诊断信息，如进程号、解释器路径、权限级别；分享日志或权限诊断前请自行检查隐私信息。
- 仓库仅包含运行源码、启动/安装脚本和依赖清单，不包含个人历史、虚拟环境、日志、测试产物或开发过程记录。

运行后自动生成的目录已被 Git 忽略：

```text
 data/    # 本机识别历史

```

## 常见问题

- **Ctrl+拖动没有反应：** 退出旧实例，重新从资源管理器启动；“权限诊断”应显示 Medium。Low 权限进程可能无法监听普通桌面的输入。
- **首次安装失败：** 确认 Python 3.11 为 64 位且包含 Tcl/Tk/pip，检查网络后重新运行启动脚本。
- **ONNX Runtime DLL 加载错误：** 检查或安装 Microsoft Visual C++ Redistributable（x64）后重试。
- **识别不准确：** 尽量框选清晰文字；复杂表格、排版和图文混排只提取文字，不还原原始布局。
- **特殊桌面/多屏：** UAC 安全桌面、锁屏、受保护内容及部分独占全屏可能无法使用；多显示器与混合 DPI 尚未充分实机验证。
